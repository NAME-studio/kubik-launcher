Политика конфиденциальности

Обновлено 12 ноября 2026 года. Лаунчер бесплатный, без рекламы и без аналитики.

Что хранится только на вашем компьютере

Настройки, список сборок, аккаунты, скины, сохранённые серверы, копии миров, Java и скачанные файлы лежат в папке данных лаунчера и в %APPDATA%\.KubikLauncher. Лаунчер не отправляет эти данные разработчику.

Какие данные уходят во внешние сервисы

Обращения уходят только тем сервисам, которые нужны для выбранного действия:

  • Mojang / Microsoft — вход в аккаунт Minecraft и загрузка версий, библиотек и ресурсов.
  • Ely.by — если вы выбрали вход через Ely.by: логин, токен сессии и скин.
  • Modrinth и CurseForge — поиск и скачивание модов, ресурспаков, шейдеров и модпаков. Им передаётся текст запроса и выбранные фильтры.
  • Firebase — только если вы пользуетесь функциями друзей и общих сборок: ник, код друга и состав сборки.
  • GitHub — проверка обновлений и скачивание новой версии.

Лаунчер не собирает аналитику, не показывает рекламу и не передаёт данные третьим лицам для маркетинга.

Ключи и токены

API-ключи (CurseForge, Firebase) и токены аккаунтов хранятся локально в файле конфигурации и используются только для запросов к соответствующим сервисам. Файл не покидает компьютер.

Логи

Логи запусков и установки пишутся в папку данных лаунчера. Они никуда не отправляются, пока вы сами не скопируете их для обращения в поддержку.

Дети

Лаунчер не предназначен для сбора данных о детях и не запрашивает возраст, имя или контакты.

Удаление данных

Чтобы удалить всё локальное, закройте лаунчер и удалите папку %APPDATA%\.KubikLauncher и папку с игровыми данными. Данные функций друзей удаляются вместе с профилем на стороне Firebase по запросу.

Вопросы по данным

Напишите в GitHub Issues — отвечаем там же.
