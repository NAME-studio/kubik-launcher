Карточка создаётся через аккаунт на сайте: **«Добавить публикацию на сайт»** (`/news/add/`), раздел **«Программы»** (`/programs/`). У них уже есть лаунчеры (Legacy Launcher), так что формат подходящий. Модерация ручная, обычно 1–3 дня.

## Категория

Программы → лаунчеры (в форме — «Программы»).

## Короткое описание (для листинга, 190 символов)

```
Бесплатный лаунчер Minecraft для Windows: отдельные сборки, Fabric/Forge/NeoForge/Quilt, каталог Modrinth, скины Ely.by и пиксельный редактор. Без рекламы, исходники открыты.
```

## Полное описание

```
Kubik Launcher — лаунчер Minecraft для Windows 10 и 11, который не заставляет ждать. При первом запуске он один раз проверяет файлы игры и кэширует Java, поэтому дальше запуск занимает около секунды.

Каждая сборка живёт отдельно: своя версия Minecraft, загрузчик (Vanilla, Fabric, Quilt, Forge, NeoForge), папка игры, память и аргументы запуска. Сборки можно дублировать, экспортировать и импортировать, а модпаки ставятся из файла — .mrpack из Modrinth и .zip с манифестом CurseForge.

Моды, ресурспаки, шейдеры и модпаки ищутся во встроенном каталоге Modrinth и CurseForge: описание, перевод, список файлов и установка в один клик. Несколько модов качаются одновременно. Если у мода нет версии под вашу сборку, лаунчер прямо пишет, для каких версий и загрузчиков он есть.

Аккаунты Ely.by и Mojang. Токены и ключи сервисов хранятся локально в зашифрованном виде (DPAPI), в облако уходят только данные друзей и общих сборок. Скины можно рисовать прямо в лаунчере — пиксельный редактор с палитрой и 3D-просмотром.

Что ещё внутри: список серверов с онлайном и пингом, друзья с чатом и общими сборками, автообновление лаунчера, русский интерфейс.

Лаунчер бесплатный, распространяется по лицензии MIT, исходный код открыт на GitHub.
```

## Возможности (список для карточки)

- Запуск игры примерно за 1 секунду после первого прогона
- Отдельные профили сборок: версия, загрузчик, папка, память, JVM-аргументы
- Загрузчики: Vanilla, Fabric, Quilt, Forge, NeoForge
- Каталог Modrinth и CurseForge, установка в один клик, параллельная загрузка
- Импорт модпаков `.mrpack` и CurseForge `.zip`
- Список серверов с онлайном и пингом
- Друзья, чат и общие сборки
- Аккаунты Ely.by и Mojang, скины в лаунчере
- Пиксельный редактор скинов с 3D-моделью
- Автообновление, русский интерфейс, бесплатно, MIT

## Ответы на вероятные вопросы модератора

- **Пиратство.** Лаунчер не содержит файлов игры, ключей и не обходит лицензию: версии качаются с официальных серверов Mojang, поддерживаются аккаунты Mojang и Ely.by.
- **Реклама и сбор денег.** Отсутствуют, монетизации нет.
- **Исходники.** Открыты, лицензия MIT — можно проверить любую строку.
- **Скачивание.** Прямые файлы в GitHub Releases плюс зеркало на сайте.

## Чеклист перед отправкой

1. Зарегистрироваться на сайте и подтвердить почту.
2. Приложить установщик `KubikLauncher-Setup-1.2.3.exe` (или ссылку на релиз, если свой файл не нужен).
3. Вставить заголовок, короткое и полное описание.
4. Загрузить 6–8 скриншотов из списка выше.
5. Указать требования, лицензию и ссылки.
6. Отправить и после одобрения проверить карточку: заголовок, версия, ссылки, скриншоты.
