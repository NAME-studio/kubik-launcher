# Kubik Launcher — тексты для каталогов

Готовые формулировки для карточек на сайтах-каталогах, в Discord, README и пресс-ките. Версия — 1.2.3.

## Название и категория

**Kubik Launcher** — лаунчер Minecraft для Windows (категория: игры → утилиты, лаунчеры).

## Короткое описание (до 200 символов)

Бесплатный лаунчер Minecraft для Windows: отдельные профили, Fabric/Forge/NeoForge/Quilt, каталог Modrinth, скины Ely.by и пиксельный редактор.

## Среднее описание (до 500 символов)

Kubik Launcher запускает Minecraft на Windows 10/11 и держит каждую сборку отдельно: своя версия игры, загрузчик модов, папка, память и настройки. Один раз проверяет файлы игры и дальше стартует за пару секунд. Внутри — каталог Modrinth и CurseForge с установкой в один клик, импорт модпаков `.mrpack` и `.zip`, аккаунты Ely.by, пиксельный редактор скинов с 3D-просмотром и общие сборки с друзьями. Без рекламы, без подписок, исходники открыты (MIT).

## Длинное описание

Kubik Launcher — лаунчер Minecraft для Windows, который не заставляет ждать. При первом запуске он один раз проверяет файлы игры, кэширует Java и больше не пересчитывает хеши при каждом нажатии «Играть»: запуск занимает около секунды.

Каждая сборка — отдельный профиль: версия Minecraft, загрузчик (Vanilla, Fabric, Quilt, Forge, NeoForge), папка игры, память и параметры запуска. Сборки можно дублировать, экспортировать и импортировать, а модпаки ставятся из файла — `.mrpack` из Modrinth и `.zip` с манифестом CurseForge.

Моды, ресурспаки, шейдеры и модпаки ищутся во встроенном каталоге Modrinth и CurseForge. Карточка мода открывается внутри лаунчера: описание, перевод, список файлов и установка; несколько модов качаются параллельно. Если у мода нет версии для вашей сборки, лаунчер прямо скажет, для каких версий и загрузчиков он есть.

Аккаунты: Ely.by и Mojang. Токены и ключи сервисов хранятся локально в зашифрованном виде (DPAPI), в облако уходят только данные друзей и общих сборок. Скины можно рисовать прямо в лаунчере — пиксельный редактор с палитрой и 3D-просмотром.

Друзья и общие сборки: код друга, статус в игре, чат и совместная сборка, которую видят все участники. Число установок показывается на сайте одной анонимной цифрой — без идентификаторов и истории.

## Ключевые возможности (для списка фич)

- Запуск игры примерно за 1 секунду после первого прогона
- Отдельные профили сборок: версия, загрузчик, папка, память, JVM-аргументы
- Загрузчики: Vanilla, Fabric, Quilt, Forge, NeoForge
- Каталог Modrinth и CurseForge, установка в один клик, параллельная загрузка модов
- Импорт модпаков `.mrpack` и CurseForge `.zip`
- Автообновление лаунчера без установщика
- Аккаунты Ely.by и Mojang
- Пиксельный редактор скинов с 3D-просмотром и палитрой
- Друзья, чат и общие сборки
- Зашифрованное хранение токенов и ключей (DPAPI)
- Русский интерфейс, бесплатно, MIT, исходники на GitHub

## Системные требования

- Windows 10 или 11, 64-бит
- 4 ГБ ОЗУ (для тяжёлых сборок — 8 ГБ и больше)
- Java не нужна: лаунчер скачивает подходящую версию сам
- Интернет для скачивания версий, модов и обновлений

## Что нового в 1.2.3

Новые коды друзей у всех (старые аннулированы, список друзей сохранён), общие игровые настройки для всех сборок, встроенный ключ Firebase — друзья и счётчик работают сразу после установки.
